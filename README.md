# Analysis package: Prichard flicker manuscript

**Manuscript:** "Noninvasive audiovisual neurostimulation differentially alters
glial responses at 20Hz and 40Hz" (Prichard / Singer lab / Wood lab).

Chronic flicker (NoFlicker / 20Hz / 40Hz, 1 h/day x 7 d) in 6-month 5xFAD vs WT
mice, both sexes. Readouts: glial morphology (IMARIS), cytokines (Luminex
32-plex), amyloid (Ab40/42 ELISA), and correlations among them.

This package contains everything needed to reproduce the **cytokine, amyloid and
correlation** statistics and figures from the raw data.

## Running it

```bash
cd Code
Rscript run_pipeline.R      # ~7 min
```

Requires R 4.5.2 with: ropls, heatmap3, rstatix, lmerTest, emmeans, nortest, FSA,
ggpubr, tidyverse, readxl. Exact versions used are in `Code/results/sessionInfo.txt`.

Every number and figure in `Code/results/` is regenerated by that one command.
Stages 09 and 10 read the PLS-DA model saved by stage 04
(`results/processed/plsda_fits.rds`), so the figures cannot drift from the stats.

## Where the numbers are

- `Code/results/stats/`: 18 tidy CSVs, one row per statistical test. **These are
  the authoritative values cited in the manuscript.**
- `Code/results/stats_round1/`: the superseded first-round values, kept for
  comparison (has its own README).
- `Code/results/revised_figures_png/`: 23 corrected data panels for the figures.
- `Code/results/cytokine|amyloid|morphology|correlations/`: vector PDFs.
- `Code/results/processed/`: intermediate tables and the saved PLS-DA fits.

## Two things a reader should know

**1. Path layout differs slightly from the original working copy.** In the lab
folder the raw inputs sat in `SARA Temp/` under several nested subfolders. Here
they are flattened into `Raw Data/` with clearer names. The files themselves are
byte-identical; only the four path variables at the top of `config.R` changed,
and the original paths are noted in a comment there.

**2. The morphology group statistics are not reproducible from this package.**
Figures 1/3/6 and Supplementary 2/3/8 were produced in MATLAB from an export that
was never included in the shared data folder. `scripts/08_morphology_stats.R`
recomputes what it can from the per-cell CSVs in `Raw Data/`, but the published
H-statistics for those panels cannot be verified without the canonical source.
Everything else (cytokines, amyloid, PLS-DA, all correlations) reproduces in
full.
